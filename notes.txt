create_react_agent : What the prompt did ? Tell LLM about tools -> Force a text format for parsing -> Teach the think —> act —> observe loop
outputs :
{
"input": "What is the capital of France ?"
"output": "The capital of France is Paris."
} 

create_agent: Tools are passed as function definitions in the API call itself — the LLM sees them natively
LLM returns structured tool_call objects — no text to parse
LangGraph's state machine handles the loop — the LLM just responds naturally

outputs: converts everything to humanmessage type
{
    "messages": [
        HumanMessage(content="What is the capital of France?"),
